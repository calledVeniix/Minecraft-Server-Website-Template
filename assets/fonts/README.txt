Put your own font file here
===========================

1. Drop your font file into this folder and name it:
      minecraft.ttf      (or minecraft.woff2)

2. Open  assets/css/style.css  and follow the short instructions at the very
   top of that file ("USE YOUR OWN MINECRAFT FONT").

3. Save and reload your browser with Ctrl + F5.

Note: only upload fonts you are allowed to use.
By default the site uses the free Google font "Pixelify Sans", which looks
very close to the Minecraft style.
